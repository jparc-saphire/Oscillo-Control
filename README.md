# Oscillo Control

TEXIO DCS-2204EをLinuxから操作するブラウザ用コントローラーです。Python 3.9以降の標準ライブラリで動作します。

## 起動

ポータルへの公開後は、J-LAN または E16 の **Monitors → Oscilloscope control** からブラウザで直接開けます。認証画面が出たら既存の **E88 DAQ Control** のログイン情報を使います。

以下は e88evb01 で単独起動する場合の手順です。

オシロに到達できるLinuxホスト（例：e88evb01）で実行します。

```sh
cd /e88/u/e88daq/slow_control/Oscillo_control
python3 server.py
```

同じホストのブラウザで [http://127.0.0.1:8765/](http://127.0.0.1:8765/) を開きます。別のPCのブラウザを使う場合は、そのPCで既存のSSH接続を使って転送します。

```sh
ssh -N -L 8765:127.0.0.1:8765 e88daq@10.105.50.22
```

SSH接続を開いたまま、PCのブラウザで同じURLを開きます。画面・波形は閲覧モードで表示できます。設定を変更するときは **Enable control** を押し、操作を終えたら **Disable control** を押します。ページを開き直すと閲覧モードから始まります。

オシロ本体の接続先は、01が `192.168.50.128:3000`、02が `192.168.50.129:3000` です。現在の **TCP/3000をそのまま使用**します。機器のIPまたはポートが変更された場合は、起動時に `--scope01`、`--scope02`、`--device-port` で指定できます。ブラウザ向けのポートは `--http-port` で変更できます。

## 操作

[Firefox での接続と操作のクイックガイド](QUICKSTART.md)

- **Instrument display** は本体の画面を表示します。**Live display** がオンのときは約1.5秒間隔で更新します。
- **CH1〜CH4** で対象チャンネルを選び、**Show selected channel** で表示を切り替えます。スケールと位置は、ノブ上のマウスホイール、`−`・`+`、または数値を入力して **Apply** か Enter を押すと変更できます。
- **Run / Stop / Single** は本体の取得操作です。トリガはソース、モード、レベル、エッジの傾きを変更できます。傾きはエッジトリガで使えます。
- **Waveform samples → Capture CHn** は取得メモリの実サンプルを描画します。**Download CSV** は全点を保存します。時間列は最初のサンプルを0秒とし、電圧または電流は機器が返したスケールと単位に基づきます。
- 波形データがない場合は、対象チャンネルで取得が完了してから再度 **Capture** します。波形ヘッダーをオフにしている場合は有効にしてください。
